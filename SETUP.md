# Настройка KICS Feature Map (веб-приложение с аккаунтами)

Приложение теперь работает на **Supabase** — бесплатном облачном сервисе, который даёт базу данных и авторизацию. Ниже — пошаговая инструкция для первого запуска.

---

## Шаг 1. Создай аккаунт и проект в Supabase

1. Зайди на **https://supabase.com** и нажми **Start your project** (или **Sign up**).
2. Зарегистрируйся (можно через GitHub или email).
3. После входа нажми **New project**.
4. Заполни:
   - **Name** — например `kics-feature-map`
   - **Database Password** — придумай надёжный пароль (запомни его, дальше он пригодится)
   - **Region** — оставь по умолчанию или выбери ближайший (например, Frankfurt / EU)
5. Нажми **Create new project** и подожди 1–2 минуты, пока он создастся.

---

## Шаг 2. Скопируй ключи в config.js

1. В дашборде проекта слева нажми: **Settings** → **API**.
2. Скопируй два значения:
   - **Project URL** — вида `https://xxxxxxxxxxxx.supabase.co`
   - **anon public** — длинная строка, начинается с `eyJ...`
3. Открой локальный файл `kics_map/config.js` и вставь их на места:
   ```js
   window.SUPABASE_CONFIG = {
     url: 'https://xxxxxxxxxxxx.supabase.co',
     anonKey: 'eyJ...'
   };
   ```
4. Сохрани файл.

> **Важно:** не используй ключ `service_role`. Он приватный и не должен попадать в код фронта.

---

## Шаг 3. Создай таблицы в базе данных

1. В дашборде слева нажми **SQL Editor** (иконка с кодом).
2. Нажми **New query**.
3. Открой локальный файл `kics_map/schema.sql`, скопируй **всё его содержимое**.
4. Вставь в поле редактора SQL и нажми **Run** (Ctrl+Enter).
5. Должно появиться сообщение «Success. No rows returned».

Всё готово — в базе создались таблицы `maps` и `map_shares` с защитой прав доступа.

---

## Шаг 4. Отключи подтверждение email (опционально, для быстрого старта)

По умолчанию Supabase требует подтверждать email при регистрации. Чтобы приложение сразу работало без письма на почту:

1. Слева **Authentication** → **Providers** → **Email**.
2. Выключи переключатель **Enable email confirmations** (переведи в `off`).
3. Сохрани.

Если оставить включённым — пользователи после регистрации будут получать письмо со ссылкой для активации, это тоже нормально (безопаснее).

---

## Шаг 5. Запусти приложение

1. Открой `kics_map/index.html` в браузере (двойной клик).
2. Появится экран входа — зарегистрируй первый аккаунт.
3. Готово! Теперь:
   - твоя таблица сохраняется в облаке,
   - можно заходить с любого устройства,
   - можно делиться доступом через кнопку **🔗 Поделиться**.

---

## Шаг 6. Публикация в интернете

Чтобы приложение было доступно другим людям (не только у тебя на компьютере):

**Вариант А — GitHub Pages** (у тебя уже настроен):
1. Залей обновлённые файлы в репозиторий `kics-feature-map` на GitHub.
2. Проверь, что в репо добавлен `config.js` с твоими реальными ключами Supabase.
3. GitHub Pages автоматически обновит сайт по адресу `https://<ник>.github.io/kics-feature-map/`.

**Вариант Б — Netlify** (если не хочешь заморачиваться с Git):
1. Зайди на **https://app.netlify.com**.
2. Перетащи папку `kics_map` прямо в браузер.
3. Сайт сразу опубликуется и получит ссылку.

## Частые вопросы

**Q: Где хранятся данные?**
В облачной базе Supabase. Никакой сервер больше не нужен.

**Q: Сколько это стоит?**
Supabase бесплатно даёт 500 МБ базы и 50 000 активных пользователей в месяц. Для личного/рабочего пользования этого хватит с большим запасом.

**Q: Безопасно ли хранить anonKey в коде?**
Да. `anonKey` — публичный ключ, который уже ограничен политиками безопасности (Row Level Security). Каждый пользователь видит и редактирует только то, что ему разрешено.

**Q: Как удалить учётную запись?**
В Supabase: Authentication → Users → выбрать пользователя → Delete user.
